# Lista de tareas web

Aplicación web sencilla para agregar tareas a una lista.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Git
- GitHub

## Estructura del proyecto

- index.html
- css/style.css
- css/style.min.css
- js/app.js
- js/app.min.js
- img/

## Proceso realizado

1. Se creó la estructura de la aplicación.
2. Se separaron los archivos HTML, CSS y JavaScript.
3. Se minificaron los archivos CSS y JavaScript.
4. Se generó un archivo ZIP con la aplicación.
5. Se creó un repositorio en GitHub.
6. Se utilizó Git para controlar las versiones del proyecto.
